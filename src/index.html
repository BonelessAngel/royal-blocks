Die laufende Runde geht verloren.

So geht's

  1. Zieh die Teile von unten auf das Feld.
  2. Ist eine Reihe oder Spalte voll, wird sie zur Pokerhand. Aus ihren 8 Karten zählen die besten 5.
  3. Sie verschwindet nur, wenn sie mindestens die Mindesthand (oben) schafft. Sonst bleibt sie gesperrt liegen – bis eine Reihe quer durch sie abgeräumt wird.
  4. Die Mindesthand steigt: Paar → Zwei Paare → Drilling.
  5. Jedes Teil hat eine Farbe: 5 gleiche Farben in einer Reihe sind ein Flush.
  6. Je besser die Hand, desto mehr Punkte. Mehrere Reihen auf einmal und Serien geben Extra-Faktoren.
  7. Passt kein Teil mehr, ist die Runde vorbei.
